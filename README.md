Saltwind Dockyard — a round-based tactical FPS in a dusk container yard. Night Tide attacks, Harbor Watch defends: plant the beacon at the crane yard (A) or the warehouse (B), or clear the other team. Between rounds, spend your winnings on rifles, a DMR, or kevlar. Tap-fire beats spraying — standing still keeps the rifle honest.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network, just static files and three.js.
